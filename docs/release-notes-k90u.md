# ColdFront v26.10.11-k90u

REDMI K90 至尊版（K90 Ultra / K90 Max）**内置风扇**控制器 —— 基于 Material Design 3 Expressive 重写。

> 本 APK 为 **debug 签名**的通用安装包（仅 arm64-v8a），安装时需允许「未知来源」。
> 非官方应用，与 Nubia / RedMagic / ZTE 无关。

## 本版更新

### 风扇开关变成真正的「总电源」

以前关掉风扇开关再打开，智能温控**不会被记住** —— 风扇确实转起来了，但温控是关的，得再手点一次，两个开关状态还会互相打架。

现在风扇开关只当总电源：

- **关闭**：风扇完全停转，同时**记住关闭前正在跑的模式**（智能温控 / 满速 / 手动）
- **重新打开**：自动恢复到那个模式，不需要再手动点一次
- 智能温控恢复时会**重新读一次温度**并按当前曲线算出目标转速，而不是套用关闭前的旧值

如果恢复智能温控时温度读不到，会退回手动档并给出错误提示，不会拿一个假温度去算曲线。

### 快捷设置磁贴：只保留一个，且与主界面同义

- 磁贴从两个减为一个，名为 **「风扇控制」**
- 它与首页「风扇开关」是**同一件事**：一键开关风扇总电源，关闭记住模式、重开自动恢复
- 图标改为**五片扇叶**的风扇造型（首页与设置页的对应行也一并换成同一图标）
- 旧版第一个磁贴与新磁贴同名同义，会原地替换；如果下拉里还残留旧的第二个磁贴，手动长按移除即可

> 桌面启动图标保持原样，未做改动。

### 版本号改为按日期自动生成

版本名格式为 **`yy.MM.dd-n`**（年月日 + 当天第几版），例如 `26.10.11-3`：

- 同一天多次构建自动递增 `n`，跨天自动归 `1`，无需手工改版本号
- `versionCode` 由版本名映射（`yymmdd * 100 + n`），保证单调递增，避免 `INSTALL_FAILED_VERSION_DOWNGRADE`
- 可在应用「设置 → 关于」中看到完整版本名与 versionCode

## 主要功能

- **手动调速**：转速滑块写入 `pwm_duty`（0–99 无极调速）
- **智能温控**：按本机温度曲线自动调速（分段线性插值），与「满速模式」互斥
- **响应速度可调**：轮询间隔 `200–5000 ms`（默认 `1000 ms`）；升降过渡时间 `0–10000 ms`（默认 `0 ms`，即直接到位）
- **满速模式**：强制满速（`target_level 4` / `pwm_duty 99`），关闭时回写节点回到静谧档
- **实时遥测**：温度、转速（RPM）、占空比；整批读取只起一个 `su` 进程
- **写入诚实性**：每个控制写按退出码判定，失败时首页横幅提示「控制指令未生效」
- **运行检查**：只读探测 Root / 风扇节点 / 温度 / 转速，逐项显示结果，不写任何节点
- **息屏停转保护**、温度迟滞、异常时安全交还系统
- **首次启动引导**、中文/英文界面、快捷设置磁贴、浅色/深色与多套调色板

## 安装与使用

1. 安装 APK
2. 授予 Root 权限
3. 完成首次启动的运行检查
4. 在「设置」中按需调整轮询间隔与升降过渡时间（建议先保持默认 `1000 ms / 0 ms`）
